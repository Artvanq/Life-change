# Контроль задач

Особистий застосунок для задач на телефоні, планшеті й комп'ютері. Встановлюється як звичайний застосунок (PWA), працює без інтернету й синхронізує все між пристроями.

## Можливості

**Задачі**
- Термін, час, пріоритет P1–P4, статус, проєкт, мітки, нотатки.
- Підзадачі з прогресом: Enter додає наступну, порядок змінюється перетягуванням, вставлений список стає кількома підзадачами, будь-яку можна винести в окрему задачу.
- Повторення: щодня, щобудня, щотижня, щомісяця, щороку або своє (кожні N днів, тижнів чи місяців, в обрані дні тижня).
- Нагадування: у час задачі, за 15 хв, 1 год, 3 год, за день, або в довільний час.
- Файли до задачі (Word, Excel, PDF, фото тощо, до 4 МБ кожен).
- Історія змін: що, коли і як змінилось, скільки разів переносили термін.

**Розділи:** Сьогодні · Усі задачі (пошук, фільтри, групування за датою, проєктом, пріоритетом чи статусом) · Календар (перетягування між днями) · Дошка статусів · Огляд (статистика, прогрес проєктів, задачі, що найчастіше відкладаються) · Кошик.

**Редагування**
- Групові дії: «Вибрати» дає змінити термін, пріоритет, статус чи проєкт, дублювати або видалити кілька задач одразу.
- «Скасувати» для будь-якої зміни (`Ctrl+Z`).
- Кошик: видалене зберігається 30 днів, його можна відновити.
- На телефоні: свайп вправо — виконано, вліво — перенести на завтра.

**Імпорт і дані**
- Імпорт задач із Word (.docx), Excel (.xlsx/.xls), CSV, тексту, з перевіркою й правками перед збереженням. Є шаблон Excel.
- Експорт в Excel, резервна копія JSON.
- Сервер щодня сам робить резервну копію й зберігає її 30 днів. Відновити можна з «Налаштувань».

**Сповіщення:** ранкове зведення на день і нагадування до задач, на всі пристрої, де їх увімкнено.

## Структура

```
api/tasks.js    — задачі (Upstash Redis)
api/files.js    — файли до задач (Vercel Blob)
api/push.js     — підписки на сповіщення і їх налаштування
api/cron.js     — нагадування, ранкове зведення, резервні копії, очищення кошика
api/backup.js   — резервні копії на сервері
api/_lib.js, api/_push.js — спільні функції
public/         — сам застосунок
```

## Деплой на Vercel

1. Залийте папку на GitHub (приватний репозиторій). На **vercel.com → Add New → Project** оберіть його й натисніть **Deploy**. Налаштування збірки міняти не треба.
2. **База задач:** **Storage → Create Database → Upstash (Redis)**, безкоштовний план, **Connect**.
3. **Файли:** **Storage → Create → Blob → Connect**. Якщо буде вибір доступу, оберіть **Private**.
4. **Змінні** в **Settings → Environment Variables**:
   - `APP_PASSWORD` — ваш пароль для входу (12+ символів);
   - `CRON_SECRET` — будь-який довгий випадковий рядок (наприклад, 32 літери й цифри). Він захищає фонові нагадування.
5. **Deployments → ⋯ → Redeploy.**

Ключі для сповіщень створюються автоматично під час першого запуску, налаштовувати їх не треба.

## Точні нагадування (5 хвилин, безкоштовно)

На безкоштовному тарифі Vercel запускає фонові задачі лише раз на день. Цього вистачає для ранкового зведення, резервних копій і очищення кошика. Щоб нагадування до задач приходили точно в час, навіть коли застосунок закритий, підключіть безкоштовний зовнішній таймер:

1. Зареєструйтесь на **cron-job.org** (безкоштовно).
2. **Create cronjob**, адреса: `https://ВАША-АДРЕСА.vercel.app/api/cron?secret=ВАШ_CRON_SECRET`
3. Розклад: **кожні 5 хвилин**. Збережіть.

Перевірка: у застосунку **Налаштування → Сповіщення** з'явиться напис «Фонові нагадування працюють». Поки застосунок відкритий, нагадування спрацьовують і без таймера.

## Встановлення і сповіщення на пристроях

- **iPhone (Safari):** Поділитися → «На екран Додому». Відкрийте застосунок з іконки → Налаштування → «Увімкнути на цьому пристрої». На iPhone сповіщення працюють лише у встановленому застосунку (iOS 16.4+).
- **Android (Chrome):** меню ⋮ → «Встановити застосунок», потім Налаштування → «Увімкнути на цьому пристрої».
- **Комп'ютер (Chrome/Edge):** значок встановлення в адресному рядку, потім так само ввімкнути сповіщення.

Кнопка «Надіслати тестове» перевіряє, що все працює.

## Імпорт: як готувати файли

**Word або текст**
```
Робота:
1. Підготувати звіт до 15.10 !1
   - зібрати дані          ← вкладений пункт стає підзадачею
   - [x] побудувати графіки ← виконана підзадача
2. Зустріч з клієнтом пт 14:00
Примітка: взяти договір    ← нотатка до попередньої задачі

Дім:                       ← заголовок або рядок із «:» стає проєктом
- Оплатити інтернет завтра
```
Заголовки Word стають проєктами, списки — задачами, вкладені рівні — підзадачами, закреслений текст — виконаними пунктами. Таблиці в Word обробляються як Excel.

**Excel або CSV.** Кожен рядок стає задачею. Стовпці розпізнаються за назвами: *Назва/Задача, Термін/Дата/Дедлайн, Час, Пріоритет, Статус, Проєкт/Категорія, Підзадачі/Кроки* (через Enter або «;»), *Нотатки/Коментар, Мітки*. Відповідність можна змінити вручну.

Старий формат `.doc` спершу збережіть як `.docx`.

**Швидке додавання одним рядком:** `Подзвонити в банк завтра 10:00 !2 #Фінанси`

| Що пишете | Що отримуєте |
|---|---|
| `сьогодні`, `завтра`, `післязавтра` | термін |
| `пн` … `нд`, `до п'ятниці` | найближчий такий день |
| `15.10`, `15.10.2026`, `2026-10-15` | дата |
| `14:30`, `о 14:30` | час |
| `!1` … `!4`, `терміново` | пріоритет |
| `#Проєкт` | проєкт (`#Мій_дім` → «Мій дім») |

## Клавіші

`N` — нова задача · `/` — пошук · `Ctrl+Z` — скасувати · `Esc` — закрити.

## Безпека

Задачі, файли й налаштування доступні лише з паролем `APP_PASSWORD`. Файли зберігаються як приватні, якщо Blob-сховище це підтримує. Фонові задачі захищені `CRON_SECRET`. Якщо змінити пароль і зробити Redeploy, усі пристрої попросять увійти знову.
